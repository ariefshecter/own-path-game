# Rencana Komprehensif Aset Game "Jalan Sendiri"

## 1. Backgrounds & Environments (`res://assets/backgrounds/`)
1. `bg_main_menu.png`: Pemandangan langit sore kota kecil tropis, kabel listrik melintang, awan peach keemasan, siluet protagonis memandang cakrawala (*A Space for the Unbound style*).
2. `bg_college_room.png`: Kamar kos masa kuliah yang sempit, meja belajar penuh tumpukan draf skripsi bertinta merah, laptop kusam menyala dengan baris kode, jendela malam gerimis.
3. `bg_campus_hallway.png`: Lorong kampus jurusan pendidikan berlantai ubin kusam dengan papan pengumuman jadwal ujian sidang.
4. `bg_coffee_stall.png`: Warung kopi tenda pinggir jalan / belakang kampus dengan bangku kayu panjang dan lampu bohlam kuning hangat.
5. `bg_fotokopi.png`: Kios fotokopi sempit penuh tumpukan kertas jilid skripsi, mesin fotokopi besar, dan aroma kertas hangat.
6. `bg_hub_room.png`: Kamar kos mandiri siang hari dengan jendela kayu terbuka, kasur lipat rapi, dan secangkir teh.

## 4. Komponen Antarmuka (UI System)
- Logo Game: Tipografi kustom *"Jalan Sendiri"* beraksen retro 90-an.
- Frame Kartu Cat Air: Panel kartu kertas tebal dengan tekstur serat kertas gading.
- Pin Node Map: Bentuk stempel lingkaran bergaya pop-up 3D datar (*flat outline 4px*).
- Garis Jalur Map: Garis putus-putus pensil dinamis berbasis shader/drawing Godot.
- Modal Box Pengaturan: Kotak kayu/kertas catatan dengan slider bertombol tutup botol / kancing retro.
