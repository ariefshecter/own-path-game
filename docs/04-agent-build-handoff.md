# Jalan Sendiri — Agent Build Handoff (Narrative Adventure)

## Mission
Bangun game narrative adventure 2D "Jalan Sendiri" dengan interaksi mikro taktil di Godot 4.3 LTS. Fokus saat ini adalah menyusun fondasi sistem dialog sinematik dan modul interaksi mikro untuk **Mini Chapter 1.1: Revisi Bab 4 & Koding Tengah Malam**.

## Non-Negotiables
1. **Genre:** 2D Narrative Adventure & Slice-of-Life Micro-Interactions (Bukan Roguelike, tanpa kartu/grinding).
2. **Visual & Suasana:** Warm watercolor paper, border pensil tebal, potret karakter ekspresif (*A Space for the Unbound style*).
3. **Mini Chapter 1.1 Scope:**
   - Adegan kamar kos malam hari jam 02:00.
   - Micro-interaction 1: Menggeser jari untuk mencoret revisi Bab 4 dosen pembimbing.
   - Micro-interaction 2: Mengetuk layar untuk mengetik program koding rahasia di laptop tua.
   - Dialog batin Rian yang menghubungkan tekanan orang tua dengan keputusasaan.
4. **Platform Target:** Android Mobile Portrait (1080x1920) / Desktop Window.

## Acceptance Criteria
- [ ] Mini Chapter 1.1 berjalan mulus dari dialog pembuka ke micro-interaction koding dan revisi skripsi.
- [ ] Efek suara ketukan keyboard mekanik dan gesekan kertas bersuara jernih.
- [ ] Setelah selesai, progres tersimpan di `GameState` dan scene beralih ke Mini Chapter 1.2.
